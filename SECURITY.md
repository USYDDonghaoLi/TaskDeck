# Security Policy / 安全政策

## 报告安全或隐私问题

如果你发现安全漏洞、意外的数据访问，或仓库/安装包中可能包含私人任务、数据库、凭据或签名材料，请使用 GitHub 的 **Report a vulnerability** 私密报告入口：

https://github.com/USYDDonghaoLi/TaskDeck/security/advisories/new

请不要为敏感问题创建公开 Issue，也不要上传真实的 TaskDeck 数据库、JSON 导出、私人任务截图、证书或密码。报告中请尽量提供受影响版本、macOS 版本、复现步骤和影响范围；示例数据应使用虚构内容。

普通功能错误和不包含敏感信息的问题可以提交到 GitHub Issues。

## 支持范围

安全修复以最新发布版本和 `main` 分支为主。TaskDeck 当前完全本地运行，不包含分析、广告或远程同步服务。

## Reporting a Security or Privacy Issue

If you discover a vulnerability, unintended data access, or possible exposure of private tasks, databases, credentials, or signing material in the repository or a release, use GitHub's private **Report a vulnerability** channel:

https://github.com/USYDDonghaoLi/TaskDeck/security/advisories/new

Do not open a public issue for sensitive reports, and never upload a real TaskDeck database, JSON export, private-task screenshot, certificate, or password. Include the affected TaskDeck and macOS versions, reproduction steps, and likely impact where possible. Use synthetic data in examples.

Ordinary bugs that contain no sensitive information may be reported through GitHub Issues.

## Supported Versions

Security work targets the latest published version and the `main` branch. TaskDeck currently runs entirely on-device and contains no analytics, advertising, or remote synchronization service.
