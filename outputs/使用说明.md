# TaskDeck 使用说明

1. 解压 `TaskDeck-macOS.zip`，把 `TaskDeck.app` 拖到“应用程序”文件夹。
2. 第一次打开时，如果 macOS 提示安全确认，请右键应用并选择“打开”。
3. 点击主窗口右上角的“设置”，可在独立设置窗口切换简体中文或英文；选择会自动保存。
4. 点击“新建精准任务”，填写大方向、具体动作、预计时间和提醒时间。
5. 点击任务卡片上的铅笔，可以修改名称、预计时长、优先级、备注和日程；右侧菜单仍可用于延期。
6. 任务支持普通、重要、紧急三个优先级，以及每天、工作日、每周、每月重复。
7. 点击任务上的播放按钮开始专注；顶部计时条可暂停、继续、结束或放弃本次计时。退出再打开应用，进行中的计时也会恢复。
8. 完成后点击任务左侧方框；右侧报告会自动生成日、周、月战绩，并显示实际专注、连续完成天数与最近 12 周热力图。
9. 点击报告右上角复制图标，可复制 Markdown 格式报告；点击 PDF 图标可选择位置并导出一页式行动报告。报告语言会跟随当前界面语言。
10. 点击主界面右上角“桌面悬浮”，打开置顶、跨桌面显示的紧凑任务板；悬浮板也支持开始和暂停专注。

任务数据只保存在本机。1.5 的主数据库位于 `~/Library/Group Containers/group.local.taskdeck.shared/TaskDeck/taskdeck.sqlite3`，主应用和 Widget 共用。

专注历史和正在运行的计时也已迁移进同一数据库。每次修改前都会在 `Backups/Database` 中建立备份，最多保留最近 30 份。

从旧版本升级不会删除已有任务。1.5 首次启动会将共享 `tasks.json`、`focus-sessions.json` 与 `focus-runtime.json` 导入 SQLite，原文件不会被移动、覆盖或删除。

1.6 正式发布版如果使用新的注册 App Group，会将开发版 SQLite 只读复制到新容器。任务、专注历史、运行中计时和旧数据库都会保留。

## JSON 导入与导出

1. 在“设置 → 数据与备份”点击“导出 JSON”，保存任务、专注历史和运行中计时的完整归档。
2. 点击“导入 JSON”可恢复完整归档；也兼容仅包含任务数组的旧版 JSON。
3. 导入前 TaskDeck 会显示确认提示，并自动备份当前数据库。

## 公开发布版隐私

正式 DMG 不包含开发者的任务、SQLite、JSON 导出、邮箱或本机编译路径。发布脚本在 Apple 公证前后都会执行隐私审计；新用户首次启动时数据库为空。

## 原生桌面 Widget

1. Widget 需要 macOS 14 或更高版本，以及使用 Apple Development/发行证书签名的 TaskDeck。
2. 安装并启动签名版 TaskDeck 后，在桌面空白处右键，选择“编辑小组件”。
3. 搜索 `TaskDeck`，可选择小号今日完成率、中号前三待办或大号任务详情。
4. 点击方框可直接完成任务；点击任务文字会打开应用并定位到该任务。
5. 原来的“桌面悬浮”窗口仍然保留，可与系统 Widget 同时使用。
