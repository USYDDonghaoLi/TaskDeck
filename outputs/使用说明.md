# TaskDeck 使用说明

1. 解压 `TaskDeck-macOS.zip`，把 `TaskDeck.app` 拖到“应用程序”文件夹。
2. 第一次打开时，如果 macOS 提示安全确认，请右键应用并选择“打开”。
3. 点击“新建精准任务”，填写大方向、具体动作、预计时间和提醒时间。
4. 使用任务右侧菜单，可以编辑任务或延期到一小时后、明天、下周一。
5. 任务支持普通、重要、紧急三个优先级，以及每天、工作日、每周、每月重复。
6. 点击任务上的播放按钮开始专注；顶部计时条可暂停、继续、结束或放弃本次计时。退出再打开应用，进行中的计时也会恢复。
7. 完成后点击任务左侧方框；右侧报告会自动生成日、周、月战绩，并显示实际专注、连续完成天数与最近 12 周热力图。
8. 点击报告右上角复制图标，可复制 Markdown 格式报告；点击 PDF 图标可选择位置并导出一页式行动报告。
9. 点击主界面右上角“桌面悬浮”，打开置顶、跨桌面显示的紧凑任务板；悬浮板也支持开始和暂停专注。

任务数据只保存在本机：`~/Library/Application Support/TaskDeck/tasks.json`。

专注历史和正在运行的计时分别保存在同一目录下的 `focus-sessions.json` 与 `focus-runtime.json`，不会改写任务文件。

从旧版本升级不会删除已有任务。1.1 引入的数据保护会继续生效：旧数据自动备份到 `~/Library/Application Support/TaskDeck/Backups/tasks-before-v1.1.json`；每次保存前还会更新 `tasks-last-known-good.json`。
