# TaskDeck 1.3

## 简体中文

- 主窗口新增“中 / EN”语言菜单，可即时切换简体中文和英文
- 语言偏好保存在本机，下次启动时自动恢复
- 任务流、任务编辑、专注计时、桌面悬浮窗和报告面板均支持双语
- Markdown 报告和 PDF 行动报告会跟随当前界面语言
- 语言设置使用独立偏好，不会修改或删除已有任务、专注记录与备份

## English

- Added a “中 / EN” menu for instant Simplified Chinese and English switching
- The selected language is stored locally and restored on the next launch
- Localized the task flow, task editor, focus timer, desktop board, and report panel
- Markdown and PDF reports now follow the selected interface language
- Language preferences are stored separately and never modify existing tasks, focus sessions, or backups
