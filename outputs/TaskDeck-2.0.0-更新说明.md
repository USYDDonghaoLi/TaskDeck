# TaskDeck 2.0.0（Build 13）更新说明

## 灵活的专注流程

- 专注任务暂停时，会立即保存这一段专注时间。
- 暂停后可点击另一项任务的播放按钮，直接切换并开始新的专注任务。
- 原任务之后仍可再次开始专注；所有片段都会累计到该任务的实际投入时间。
- 如果专注片段跨越午夜，日、周、月报告会按片段实际落入的日期分别计算。
- “放弃本次记录”会清除当前这一轮已保存的暂停片段，不影响更早的历史记录。

## 编辑与预计时长

- 专注进行中仍可编辑任务名称、方向、优先级和预计时长。
- 修改名称、方向或预计时长后，专注栏会立即同步最新信息。
- 新建任务、编辑任务和菜单栏快速添加统一使用数字填空。
- 可选择“分钟”或“小时”，两种输入方式的总时长上限均为 60 小时。

## 防误触恢复

- 已完成任务右侧新增明确的恢复按钮，也可继续点击左侧勾选框或更多菜单恢复。
- 恢复只会取消完成状态；任务 ID、名称、方向、备注、预计时长、优先级、日期、子任务和专注历史全部保留。

## 数据安全与验证

- 本次更新不修改 SQLite 表结构，不需要删除或重建数据库。
- 每次任务或专注修改前仍会自动创建备份。
- 10 项隔离 XCTest 全部通过，测试仅使用临时数据库，不接触个人任务数据。
