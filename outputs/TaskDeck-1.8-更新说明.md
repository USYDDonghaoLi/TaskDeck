# TaskDeck 1.8

## 中文

- 新增可勾选子任务，可在任务编辑器中添加、改名和删除，也可在任务卡片直接完成。
- 重复任务会生成一套新的未完成子任务，原步骤历史不受影响。
- 新增全局搜索：覆盖任务名、大方向、备注和子任务。
- 新增复合筛选：优先级可与逾期、今天、未来计划、未安排日期叠加。
- 新增菜单栏快速添加，无需先打开 TaskDeck 主窗口。
- 新增快捷键：`⌘N` 新建、`⌘F` 搜索、`⌘⌥F` 清除筛选、`⌘⇧D` 打开桌面板。
- JSON 归档升级为 schema v4，旧版 JSON 仍可导入。

## English

- Added checkable subtasks with create, rename, delete, and inline completion controls.
- Recurring tasks receive fresh incomplete subtasks without changing the original step history.
- Added global search across task titles, directions, notes, and subtasks.
- Added compound priority and date filters for overdue, today, upcoming, and unscheduled work.
- Added menu-bar quick add without requiring the main window.
- Added shortcuts: `⌘N`, `⌘F`, `⌘⌥F`, and `⌘⇧D`.
- Upgraded JSON archives to schema v4 while preserving legacy imports.
